# Haven 🌿

An AI-powered emotional wellness companion that provides users a safe space to express their feelings and receive personalized support.

## Features

- 🌱 Emotion-based guided journeys
- 🤖 Gemini AI powered conversations
- 🎙️ Voice AI interaction
- 💙 Mental wellness support experience
- ✨ Interactive calming UI

## Tech Stack

- React
- Vite
- JavaScript/TypeScript
- Gemini API
- Web Speech API

## How to Run

npm install

npm run dev

## AI Integration

Haven uses Google's Gemini AI to provide personalized conversations based on user inputs.
